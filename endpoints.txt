--------------------------------------------------------------------------------
RECENT MAJOR IMPLEMENTATIONS & UPDATES SUMMARY
--------------------------------------------------------------------------------

1. FIX: Upfront Payment Prompt on Initial Booking
   - Previously in user_app/nearby_workers_screen.dart, creating a booking was
     immediately redirecting to PaymentScreen (forcing upfront payment before worker arrival).
   - FIX: Removed immediate PaymentScreen redirect. Now navigates to My Bookings
     screen with a toast "Service Booked Successfully! Partner assigned for inspection."
   - Upfront "Pay Now" button removed from pending booking card.

2. OTP Generation & Verification Flow
   - 4-digit OTP is displayed on User App booking card.
   - Worker App has an AlertDialog popup ("Enter Customer Start OTP").
   - Backend PATCH /api/app/bookings/:id/status verifies OTP before updating
     status to 'in_progress'.

3. Worker Custom Invoice & Razorpay Payment Flow
   - Worker App features WorkerCreateInvoiceScreen where worker enters line items
     and total amount, posting to POST /api/app/bookings/:id/submit-invoice.
   - Backend updates bookings.amount = totalAmount and creates invoice.
   - User App BookingCard updates dynamically once invoice is submitted, displaying
     a prominent "Pay Now (₹<amount>)" button leading to PaymentScreen with Razorpay integration.

4. Firebase Cloud Messaging (FCM) Push Notifications Setup
   - Installed `firebase-admin` package in backend.
   - Updated Database Schema (db.js) to add `fcm_token` column to `users` and `workers` tables.
   - Created FCM Service module (backend/src/utils/fcm.service.js) for handling push dispatches
     and DB notification fallbacks.
   - Added endpoints POST /api/app/user/fcm-token and POST /api/app/worker/fcm-token.
   - Wired real-time push notification triggers across backend operations:
     - New Booking -> Push to Worker ("🔔 New Job Assignment!")
     - Worker Accepts -> Push to User ("✅ Worker Accepted! Check OTP")
     - OTP Verified -> Push to User ("🛠️ Work Started!")
     - Invoice Submitted -> Push to User ("🧾 Custom Invoice Ready! Pay ₹399 Now")
     - Payment Verified -> Push to Worker ("💰 Payment Received!") & User ("🎉 Payment Successful!")
   - Updated Flutter User App and Worker App (main.dart & ApiService) to auto-sync FCM token on startup.
